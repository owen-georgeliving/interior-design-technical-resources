# Interior Design & Technical Resources

A collection of interior design development references, technical documentation resources, and project coordination materials maintained by **George Living**.

## About This Repository

This repository is intended for interior designers, architects, project managers, and other professionals involved in residential, hospitality, and commercial interior projects.

Our focus is on connecting design intent with practical technical information, product engineering, custom joinery, and coordinated product supply.

## Resource Categories

- **3D Design References** — Interior visualization and design development references.
- **Custom Joinery** — Cabinetry, wardrobe, kitchen, and architectural woodwork planning.
- **Technical Drawings** — Drawing review considerations and documentation checklists.
- **Material Specifications** — Material, finish, hardware, and product specification references.
- **Project Coordination** — Design handover and product coordination templates.

Resources and templates will be added as they become available.
